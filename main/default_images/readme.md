# default_images — Bazel Migration

Pure-data package. Contains the raw PNG/BMP source images for all OOo toolbar icons
and UI decorations. No compilation step is needed — files are either embedded into
`.res` files by the RSC pipeline or packed into `images.zip` for runtime loading.

## Targets

| Target | Output | Use |
|---|---|---|
| `vcl_images` | filegroup | VCL `.res` embedded images (vcl/res/**) |
| `shared_images` | filegroup | Other shared images (res/*.png, res/*.bmp) |
| `desktop_res_images` | filegroup | Desktop + commandimagelist PNGs |
| `<module>_res_images` | filegroup | Per-module images fed to RSC pipeline |
| `images` | `images.zip` | Runtime toolbar icons staged to `share/config/` |

## images.zip

Built by the `images_zip` Starlark rule in `build/rules/images.bzl` using
`build/tools/make_images_zip.pl` (Archive::Zip via Strawberry Perl).

In the dmake build this was produced by `packimages.pl`, which uses `.ilst` files
(generated by the RSC pipeline) to select exactly which images go into each zip.
The Bazel version zips all PNGs from every module subdirectory except `vcl/res/`
(those are baked into `.res` files and not loaded from the zip at runtime).

`images_industrial.zip` is built separately by `//main/ooo_custom_images:images_industrial`.
`images_classic.zip` is deferred (requires extracting `classic_images.tar.gz`).
`images_hicontrast.zip` is deferred (requires the full packimages `.ilst` pipeline).
