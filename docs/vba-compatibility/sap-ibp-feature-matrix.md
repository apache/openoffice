# SAP IBP VBA Samples — VBA Feature Matrix

This document maps each VBA construct observed in the extracted SAP IBP VBA
source to its current support status in the Apache OpenOffice (AOO) source tree
on the `symphony-vba` branch.

______________________________________________________________________
