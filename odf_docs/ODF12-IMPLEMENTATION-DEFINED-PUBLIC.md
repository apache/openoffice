# DRAFT: Apache OpenOffice: ODF 1.2 implementation-defined values

> **DRAFT. Work in progress, for discussion only.** This document has not been reviewed or approved by the Apache OpenOffice project and may change or be withdrawn. It is not an announcement, and it makes no claim that Apache OpenOffice conforms to ODF 1.2.


ODF 1.2 Part 1 (section 2.3.1 B) requires a conforming producer to be accompanied by a document that defines the implementation-defined values it uses, and section 2.3.2 B asks an extended producer to document the foreign elements and attributes it writes. This document does both for Apache OpenOffice. It describes the behaviour of the OpenOffice development source of 2026-10-29 and is to be updated for the release that carries the claim.

It covers ODF 1.2 Part 1 and Part 3 (OASIS Standard, 29 September 2011). Part 2 (the formula evaluator) is not claimed; see section 5.

## 1. Conventions

- **Strict** is the ODF 1.2 non-extended save mode. **Extended** is ODF 1.2 Extended. Unless an entry says otherwise, strict and extended behave the same.
- "Implementation-dependent" items (which section 1.2 does not require a producer to document) are listed too, marked (dep).
- "Not produced" means OpenOffice never writes the construct; the entry then records only what the importer does.
- Entries are keyed by the section number of the specification.

## 4. Foreign elements and attributes (§2.3.2 B)

Foreign means a namespace not declared by the ODF 1.2 schema. Namespace prefixes used only inside attribute values (`ooo:`, `ooow:`, `oooc:`, `of:`, `dom:`, `xsd:`) are not listed.

### 4.1 Written in extended mode only

| Namespace | Items |
|---|---|
| `officeooo` = `http://openoffice.org/2009/office` | `officeooo:annotation` (Impress/Draw, in `draw:page` and `style:master-page`; carries `svg:x`, `svg:y` and, when the size is non-zero, `svg:width`, `svg:height`; children `dc:creator`, `dc:date`, text); `officeooo:event-listeners` (Calc, in `table:table`; children are ODF `script:event-listener`) |
| `drawooo` = `http://openoffice.org/2010/draw` | attribute `drawooo:display` (`none`, `printer`, `screen`) on any shape except page, handout and chart shapes; omitted when visible and printable. declared in Impress/Draw, Writer and Calc in extended mode; the shared shape exporter writes the attribute only when the namespace is declared |
| `textooo` = `http://openoffice.org/2013/office` | `textooo:sender-initials` (Writer, in `office:annotation`) |

### 4.5 Outside ODF 1.2 entirely

- Base report sub-documents use `rpt` = `http://openoffice.org/2005/report` (`office:report` and about 20 `rpt:` elements); the report document type is not an ODF 1.2 document type (reportdesign `xmlExport.cxx:233,272-1565`). The importer also accepts the OASIS report URI, which AOO never writes.
- Non-ODF streams: `VersionList.xml` (`http://openoffice.org/2001/versions-list`) and the Basic and dialog library containers (`http://openoffice.org/2000/*`).
- Read but never written: `loext:graphic-properties` in paragraph styles (imported as paragraph fill).

## 5. Part 2 (formula evaluator)

AOO does not claim the Part 2 evaluator groups (Small, Medium, Large). The 77 implementation-defined or implementation-dependent items of Part 2 therefore have no AOO values in this document. For producing documents, AOO writes `table:formula` in the `of:` namespace in ODF 1.2 (section 2.3, §19.642).
